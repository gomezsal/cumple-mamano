# Feliz Cumple 25 🎂

Interactive birthday website (static: HTML + CSS + JS, no build step).

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000

## Publish with GitHub Pages
1. Create a new repository on GitHub and upload **all** the files and the `assets` folder (keep the structure).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Easy edits (in `index.html`)
- Page color around the frame: `--page` in the CSS.
- Frame cream color: `--bg`.
- Texts: the `say('...')` lines and the `<h1>` in the HTML.
- Polaroids per item: the `p:[...]` lists in `ITEMS`.
